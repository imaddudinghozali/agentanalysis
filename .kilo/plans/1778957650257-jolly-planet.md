# Project Analysis: MCP Trading Strategy Discipline Engine

## Overview
This project implements a trading strategy discipline engine for XAUUSD (Gold) with XAGUSD (Silver) as secondary context. It follows ICT/SMC (Inner Circle Trader/Smart Money Concepts) methodology with a WAIT-first approach.

## Project Structure
- **backend/**: Python/FastAPI application (app.py, services/, schemas/, storage/, strategy/)
- **frontend/**: React/Vite dashboard (index.html, package.json, src/)
- **data/**: Fixture CSV data for testing
- **tests/**: Test fixtures and manifests
- **.kilo/**: Kilo configuration (plans directory)

## Key Components

### Backend (Python/FastAPI)
1. **app.py**: Main FastAPI application with endpoints:
   - POST /webhook/tradingview - Candle ingestion from TradingView
   - POST /api/import-csv - CSV data import
   - POST /api/analyze - Market analysis endpoint
   - GET /api/status - Data freshness and missing timeframe status
   - GET /health - Health check

2. **Services**:
   - analysis_service.py: Core analysis logic (strategy pipeline, fallback analysis)
   - ingestion_service.py: CSV and webhook data ingestion
   - report_service.py: Narrative report generation

3. **Storage**:
   - storage/candles.py: Candle repository with SQLite persistence
   - storage/database.py: Database initialization

4. **Strategy Module**: ICT/SMC implementation with modules for:
   - pipeline.py: Main strategy orchestration
   - dol.py: Demand/Supply zone detection
   - liquidity.py: Liquidity sweep detection
   - ssmt.py: Secondary Symbol Market Time alignment
   - structure.py: Market structure analysis
   - And other supporting modules

### Frontend (React/Vite)
- Simple dashboard displaying deterministic engine output
- Uses sample data from frontend/src/sampleAnalysis.js when API unavailable
- Posts analysis requests to /api/analyze endpoint

## Data Flow
1. Data Ingestion: Webhook/CSV → IngestionService → CandleRepository (SQLite)
2. Analysis Request: POST /api/analyze → AnalysisService
3. Analysis Processing:
   - Load market data from repository
   - Attempt to run strategy pipeline (strategy.pipeline.analyze_market)
   - Fallback to built-in analysis if pipeline unavailable
   - Generate narrative report
4. Response: Return analysis results including trade idea, gate result, HTF context, etc.

## Configuration
- Requirements: See requirements.txt (FastAPI, Pydantic, etc.)
- Frontend dependencies: Vite, React, lucide-icons
- Database: SQLite (initialized via storage.database.init_db)

## Setup Instructions (from README.md)
**Backend**:
```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --reload
```

**Frontend**:
```bash
cd frontend
npm install
npm run dev
```
